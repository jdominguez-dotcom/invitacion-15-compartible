# Invitación de 15 - Compartible

Página simple que genera una invitación de 15 editable y guarda el estado en la URL (hash). Abre `index.html` en el navegador o visita la página publicada en GitHub Pages.

- Uso: abre la página, edita los campos y copia el enlace con "Copiar enlace" para compartir.
- Genera datos aleatorios al cargar si no hay estado en la URL.

Sitio esperado (GitHub Pages): https://jdominguez-dotcom.github.io/invitacion-15-compartible/
